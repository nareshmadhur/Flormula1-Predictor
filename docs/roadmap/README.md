## How To Use This

- `P0`, `P1`, and `P2` are the only standing increments unless a future slice is independently testable enough to deserve its own increment.
- `SPR-###` files group increments into practical delivery slices.
- Each increment file includes scope, components introduced, dependencies, and test guidance.
- Each sprint file includes quick links, current status, and validation targets.
- Public website copy should follow the [Content Guidelines](</Users/nareshmadhur/Tech Projects/Flormula1-Predictor/docs/content-guidelines.md>) so roadmap, legal, and implementation notes do not leak into user-facing pages.

## Commercialization Track

The commercialization plan is intentionally separate from `P0/P1/P2` execution because it includes legal, brand, pricing, and go-to-market readiness in addition to product work.

Recommended commercial sequence:

- `C0`: brand, legal, and trust readiness
- `C1`: invite and join group flow
- `C2`: organizer-paid subscription
- `C3`: reminder and recap conversion loops
- `C4`: product analytics and commercial metrics
- `C5`: public share cards and referral loops

## Recommended Increment Template

Each increment should document:

- `ID`
- `Objective`
- `User / admin value`
- `Functional components embedded`
- `User journey impact`
- `Scope`
- `Out of scope`
- `Technical components introduced or changed`
- `Data model impact`
- `Test plan`
- `Dependencies`
- `Status`
